# Эмулятор оболочки ОС с виртуальной файловой системой

Практическая работа № 1 по дисциплине «Конфигурационное управление»,
вариант 20. Язык реализации — Python 3.8+ (только стандартная библиотека).

## 1. Общее описание

Консольный (CLI) эмулятор командной строки UNIX-подобной ОС. Файловая
система — виртуальная (VFS): источником служит директория на диске, она
целиком читается в память при запуске, все операции (в том числе `chown`)
выполняются только в памяти, диск не изменяется.

Приглашение к вводу содержит имя VFS (имя папки-источника) и текущий
каталог: `deep:/a/b$ `. Ввод разбивается на команду и аргументы по пробелам
(кавычки не обрабатываются).

Структура репозитория:

| Путь | Назначение |
|------|------------|
| `src/` | исходный код (`main.py`, `shell.py`, `commands.py`, `vfs.py`, `config.py`, `script.py`, `cmdparser.py`) |
| `tests/` | модульные тесты (`unittest`) |
| `scripts/` | скрипты реальной ОС для проверки параметров и вариантов VFS |
| `examples/vfs/` | примеры VFS: `minimal`, `files`, `deep` (5 уровней) |
| `examples/startup/` | стартовые скрипты эмулятора для каждого этапа |
| `run.sh`, `Makefile` | запуск, тесты и демонстрации |
| `dlya_starta.txt` | команды запуска и тестирования |

## 2. Описание функций и настроек

### Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--vfs PATH` | путь к директории на диске, из которой строится VFS. Без параметра используется пустая VFS с именем `vfs` |
| `--script PATH` | путь к стартовому скрипту |

При запуске выводятся все заданные параметры (`[debug] ...`) и статистика
загруженной VFS. Если директория VFS не найдена, процесс завершается с
кодом 2. Неизвестный параметр — код 2.

### Стартовый скрипт

Команды выполняются последовательно; на экран выводятся и ввод (с
приглашением), и результат. **Ошибочные строки пропускаются**, о каждой
сообщается в stderr (`script: <файл>: line N: '<команда>' failed ...`).
Пустые строки и строки, начинающиеся с `#`, игнорируются. После
выполнения скрипта эмулятор переходит в интерактивный режим, если скрипт
не завершился командой `exit`.

### Команды

| Команда | Описание |
|---------|----------|
| `ls [-l] [-a] [ПУТЬ...]` | содержимое каталога или файлы. `-a` — показывать скрытые (`.name`), `-l` — подробный формат: права, владелец, группа, размер, дата, имя. Права в выводе условные: `drwxr-xr-x` / `-rw-r--r--`. Для нескольких путей выводятся заголовки `путь:` |
| `cd [ПУТЬ]` | смена текущего каталога; без аргумента — корень; поддерживаются `.` и `..` |
| `date [-u] [+ФОРМАТ]` | текущие дата и время; `-u` — UTC; `+ФОРМАТ` — формат `strftime`, например `date +%Y-%m-%d` |
| `tail [-n N] ФАЙЛ...` | последние N строк (по умолчанию 10); для нескольких файлов выводятся заголовки `==> файл <==` |
| `chown [-R] ВЛАДЕЛЕЦ[:ГРУППА] ПУТЬ...` | смена владельца/группы в памяти. `:ГРУППА` меняет только группу, `ВЛАДЕЛЕЦ:` не меняет группу, `-R` — рекурсивно |
| `exit` | завершение работы |

Коды завершения команд: 0 — успех, 1 — ошибка, 127 — команда не найдена.
Имена пользователей и групп в `chown` не проверяются (в VFS нет базы
пользователей). Двоичные файлы читаются как байты; `tail` декодирует их
с заменой нечитаемых символов.

## 3. Сборка, запуск и тесты

Сборка не требуется. Нужен Python 3.8+.

```bash
./run.sh --vfs examples/vfs/deep               # запуск (или make run ARGS="...")
make test                                      # все модульные тесты
make demo2                                     # скрипт ОС: параметры (этап 2)
make demo3                                     # скрипт ОС: варианты VFS (этап 3)
make demo4                                     # стартовый скрипт этапа 4
make demo5                                     # стартовый скрипт этапа 5
```

Тесты без `make`: `python3 -m unittest discover -s tests -v`.

Скрипты реальной ОС (`scripts/`): `stage2_params.sh` вызывает эмулятор со
всеми вариантами параметров, `stage3_vfs.sh` — с VFS `minimal`, `files`,
`deep`, а также с несуществующей директорией и файлом вместо директории.
Стартовые скрипты эмулятора: `examples/startup/stage2.txt` ... `stage5.txt`.

## 4. Примеры использования

Запуск со стартовым скриптом (даты в `ls -l` зависят от времени
файлов на диске):

```text
$ ./run.sh --vfs examples/vfs/deep --script demo.txt
[debug] launch parameters:
[debug]   script = demo.txt
[debug]   vfs = examples/vfs/deep
[debug] vfs 'deep' loaded: 5 dirs, 6 files
deep:/$ ls -l
drwxr-xr-x user user   4096 Oct 17 07:28 a
drwxr-xr-x user user   4096 Oct 17 07:28 docs
deep:/$ cd a/b
deep:/a/b$ ls
c
mid.txt
deep:/a/b$ tail -n 2 c/deep.txt
Level 4 file.
Second line.
deep:/a/b$ chown -R alice:dev /a
deep:/a/b$ ls -l /a
drwxr-xr-x alice dev   4096 Oct 17 07:28 b
-rw-r--r-- alice dev     14 Oct 17 07:28 top.txt
deep:/a/b$ cd /nope
cd: /nope: No such file or directory
script: demo.txt: line 7: 'cd /nope' failed with status 1
deep:/a/b$ exit
script finished with 1 error(s)
```

Интерактивный режим:

```text
$ ./run.sh --vfs examples/vfs/files
[debug] launch parameters:
[debug]   script = <not set>
[debug]   vfs = examples/vfs/files
[debug] vfs 'files' loaded: 0 dirs, 3 files
files:/$ ls
data.csv
notes.txt
todo.txt
files:/$ tail -n 2 notes.txt
note line 14
note line 15
files:/$ date -u +%Y-%m-%d
2026-10-17
files:/$ foo
foo: command not found
files:/$ <Ctrl+D>
```

Полные сценарии со всеми режимами команд и ошибками — в
`examples/startup/stage4.txt` и `examples/startup/stage5.txt`.
