# Задача 1. Список пользователей из /etc/passwd

## Задание
Вывести отсортированный в алфавитном порядке список имён пользователей в файле passwd.

## Команда

grep -v '^#' /etc/passwd | cut -d: -f1 | sort

## Результат
См. results/task1.txt

## Объяснение
- grep -v '^#' /etc/passwd — убрать строки-комментарии
- cut -d: -f1 — взять первое поле (имя пользователя)
- sort — отсортировать по алфавиту
